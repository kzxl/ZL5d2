# ZeroLantern 5D2 — Dedicated Canon EOS 5D Mark II Still Photography OS

## Target Hardware & Firmware
- Camera: Canon EOS 5D Mark II (DIGIC 4, Full-Frame 21.1 MP)
- Firmware Version: 2.1.2
- Base Port Path: `platform/5D2.212/`
- Target Architecture: ARMv5TE (ARM946E-S, Soft-Float, Strict Alignment)

## Core Architectural Invariants
1. **Dedicated 5D Mark II Still Photography Focus**:
   - All other camera platforms have been completely stripped.
   - All video recording subsystems (MLV RAW video, H.264 bitrate modifications, FPS overrides) are stripped.
   - Maximizes SDRAM memory available for 14-bit RAW buffer and sensor DMA.
2. **Hybrid C & Safe Rust Architecture**:
   - Bootloader, RAM instruction hijacking, and hardware ROM stubs remain in C/ASM (`src/boot-d45.c`, `platform/5D2.212/stubs.S`).
   - High-level still photography logic, histogram analysis, and ND calculation are powered by safe `#![no_std]` Rust (`rust/crates/zero-photo`, `rust/crates/zero-d4`).
3. **Firmware & Hardware Safety Invariants**:
   - Never modify DIGIC 4 register addresses in `platform/5D2.212/consts.h` or stubs in `stubs.S` without empirical memory dump verification.
   - Maintain `AUTOEXEC_BASE = 0x800000` and `RESTARTSTART = 0x4E000` memory map invariants.
