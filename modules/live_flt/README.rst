Live Filter Module (live_flt)
=============================

Real-time computational optical filters simulated directly inside the LiveView
hardware pipeline on Canon DSLR cameras (DIGIC 4).

Features
--------

- **Electronic Live GND (Graduated ND)**:
  Darkens the sky portion of the frame in real time to visualize balanced
  exposures during sunrise and sunset. Horizon level and attenuation strength
  (-1 EV to -4 EV) are fully adjustable.
- **Monochrome Preview**:
  Real-time chroma stripping with enhanced contrast for high-impact black and white
  visualization in the style of Leica Monochrom.
- **Live ND Sim**:
  Real-time preview attenuation to simulate neutral density filters.
